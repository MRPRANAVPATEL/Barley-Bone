# Barley & Bone | Premium Website Template

**Thoughtfully built by Pranav Patel.**

Premium editorial pet eCommerce storefront template for dog accessories, built with HTML, CSS and JavaScript.

> **Portfolio / practice project:** Created for personal practice, design exploration and showcasing frontend development. This repository is a website template, not an operating store or publishing platform. Use and adapt at your discretion, and review asset rights and third-party dependencies before production use.

## About the template

Barley & Bone is a polished, single-page frontend concept designed for premium pet boutiques, lifestyle brands, and designer dog-accessories stores. It focuses on visual storytelling, considered typography and responsive interactions without requiring a frontend framework or build process.

## Features

- Boutique dog-accessories branding and editorial storytelling
- Featured collections for walking, rest, play and everyday essentials
- Interactive demo product search and shopping bag drawer
- Responsive menus, animations and product discovery
- Newsletter and checkout interface demonstrations

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

1. Clone or download this repository.
2. Open `index.html` in your browser, or run it using VS Code Live Server.
3. No install, build process or package manager is needed.

## Live demo

- **GitHub Pages:** https://mrpranavpatel.github.io/Barley-Bone/ (available after Pages is enabled and published)

## Deployment

This repository includes a root-level `index.html` and can be hosted as a static website on GitHub Pages or Vercel.

For GitHub Pages, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and save. Once GitHub finishes publishing, the GitHub Pages URL above should work.

## Important notes

This is a frontend demo, not a production shop. Search and cart use demo data, and checkout does not process real payments or place orders.

External media, imagery and fonts may require an internet connection. Review licensing and replace demonstration content before commercial use.
